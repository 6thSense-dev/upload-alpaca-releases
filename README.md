# 6thSense Upload Alpaca: installers

Installers for the 6thSense Upload Alpaca desktop app. This repository holds **no source code**; the app is a window
around https://upload.6thsense.dev/, so website changes reach every app without a new installer.

Download the latest version from [Releases](https://github.com/6thSense-dev/upload-alpaca-releases/releases/latest):

- **Windows:** `6thSense-Upload-Alpaca-Setup-<version>.exe`. After the first install, Windows updates itself.
- **Mac (Apple Silicon, M1 and newer):** `6thSense-Upload-Alpaca-<version>-arm64.dmg`
- **Mac (Intel):** `6thSense-Upload-Alpaca-<version>-x64.dmg`. Macs show an "Update" prompt when a new version is out.

The installers are not code-signed: Windows shows "unknown publisher" and macOS asks you to approve the app once.
